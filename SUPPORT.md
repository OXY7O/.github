# OXY7O Community Support

OXY7O repositories are maintained independently. This page provides organization-wide routing guidance, not a guaranteed support service or response-time commitment.

## Where to ask

- **KAORI application:** use the [KAORI issue tracker](https://github.com/OXY7O/KAORI/issues) for reproducible bugs and accepted work proposals. Follow the repository's own `CONTRIBUTING.md`, `SUPPORT.md`, and issue forms when present.
- **KAORI website:** use the [website issue tracker](https://github.com/OXY7O/kaori-website/issues) for website-specific problems.
- **KAORI documentation:** use the [documentation issue tracker](https://github.com/OXY7O/kaori-docs/issues) for documentation-specific corrections.

Check existing issues before opening another. Include the affected repository, version or commit, reproducible steps, expected versus observed behavior, and sanitized logs where appropriate. Do not post credentials, private endpoints, customer data, or internal operational evidence.

## Security reports

**Do not disclose vulnerabilities or secrets in public issues or discussions.** Consult the affected repository's `SECURITY.md` and its repository-specific private vulnerability reporting route, if enabled. If a private route is not available or cannot be verified, contact the repository maintainers privately using an established trusted channel. Do not assume organization-wide security reporting is enabled.

## Community and roadmap boundaries

Public Discussions, if enabled for an individual repository, are for conversation and triage—not automatic engineering acceptance. An idea or external pull request becomes committed work only after maintainers accept an issue under that repository's existing governance. The KAORI application staging and human UAT gates remain authoritative for application changes.

There is no implied support SLA, warranty, or promise that roadmap features, hosted SaaS, or public contribution intake are currently available. Repository-local policies and licensing take precedence over this shared default.
